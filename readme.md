# Expense Tracker Web Application
  Project Overview
  Expense Tracker is a web-based application developed using Python and Flask that helps users manage and track their daily expenses efficiently. The application allows users to add, view,   update, and delete expense records while storing data in an SQLite database.
  
 # Features
 
  Add new expense records
  
  View all expenses in a structured format
  
  Update existing expense details
  
  Delete expense records
  
  Store data using SQLite database
  
  User-friendly web interface
  
  CRUD (Create, Read, Update, Delete) operations

# Installation

  Clone the Repository
  
  Bash
  
  git clone https://github.com/ganeshingle/expense-tracker-with-filter.git
  
  Navigate to Project Directory
  
  Bash
  
  cd expense-tracker
  
  Install Required Packages
  
  Bash
  
  pip install flask
  
  Run the Application
  
  Bash
  
  python app.py
  
  Open in Browser

  http://127.0.0.1:5000
  
#  Database

  The application uses SQLite for storing expense records. The database contains details such as:
  
  Description
  
  Amount
  
  Category
  
  Date
